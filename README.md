
# GameZone - Sistem Rental PlayStation

## Deskripsi
GameZone adalah program berbasis Java Console untuk menghitung biaya penyewaan PlayStation 4 dan PlayStation 5.

## Fitur
- Input nama pelanggan.
- Pilihan PS4 dan PS5.
- Perhitungan biaya sewa berdasarkan durasi.
- Diskon 10% untuk durasi bermain minimal 3 jam.
- Pilihan tambahan minuman seharga Rp5.000.
- Menampilkan struk pembayaran.
- Transaksi berulang.

## Teknologi
- Java
- Apache NetBeans IDE
- Scanner untuk input pengguna

## Cara Menjalankan
1. Buka project menggunakan Apache NetBeans IDE.
2. Pastikan JDK sudah terpasang.
3. Buka file GameZone.java.
4. Jalankan program dengan menekan F6.
5. Masukkan data pelanggan sesuai petunjuk program.
